# MORG.EXE

A retro-inspired mystical web experience featuring Morg, a digital entity with her own personality, designed to feel like a relic of the early internet. Combining occult aesthetics, interactive guidance, and nostalgic web design.

### Currently implemented
- Retro-inspired interface based on early 2000s websites.
- Character-centered layout featuring Morg.
- User configuration interface for zodiac sign.
- Selection of mystical guidance categories.
- Loading messages and interactive experience structure.
- Final message display area.
- Share functionality layout.

### Planned features
- Morg's personality and behavioral system.
- Dynamic, personalized messages based on user selections.
- Zodiac-based interpretations.
- Different types of advice and readings.
- More expressive and randomized interactions.
- Refinement of the user experience and interactive elements.

### Technologies
- HTML
- CSS
- JavaScript

*An experiment in creating a little digital witch with a personality of her own.*
